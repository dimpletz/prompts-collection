# hooks-reference

* [GitHub Copilot Hooks Reference (Copilot CLI and Cloud Agent)](github-copilot-hooks-reference.md) - Hub for the official GitHub Docs hooks reference covering Copilot CLI and Copilot cloud agent — surface differences, the full hook event catalog, payload format conventions, and links to focused concepts for each topic.
* [GitHub Copilot Hooks Locations and Scoping](github-copilot-hooks-locations.md) - Where Copilot CLI and Copilot cloud agent load hook configuration from, including load order, policy hooks, and agent-scoped hooks declared in custom agent frontmatter.
* [GitHub Copilot Cloud Agent Hooks Execution Environment](github-copilot-hooks-cloud-agent-environment.md) - Constraints of the ephemeral Linux sandbox that Copilot cloud agent uses to run hooks, including honored fields, filesystem, network, environment variables, and interactivity.
* [GitHub Copilot Hooks Disable All Hooks](github-copilot-hooks-disable-all-hooks.md) - How the disableAllHooks flag skips hook configuration without deleting it, and how its scope differs between a single hooks file and repository settings.json.
* [GitHub Copilot Command Hooks](github-copilot-hooks-command-hooks.md) - Configuration format and fields for Copilot command hooks (bash, powershell, command, exec/args), plus progress messages, stdout parsing rules, and sandboxed-session behavior.
* [GitHub Copilot HTTP Hooks](github-copilot-hooks-http-hooks.md) - Configuration and field reference for Copilot HTTP hooks that POST the hook input payload as JSON to a URL, including TLS rules, header env expansion, and cloud agent firewall limits.
* [GitHub Copilot Prompt Hooks](github-copilot-hooks-prompt-hooks.md) - Configuration and behavior of Copilot prompt hooks, which auto-submit text or a slash command on sessionStart, including CLI and cloud agent limitations.
* [GitHub Copilot Hooks Session and Prompt Event Payloads](github-copilot-hooks-session-and-prompt-payloads.md) - Input and output payload shapes for the sessionStart, sessionEnd, userPromptSubmitted, and userPromptTransformed hook events in both camelCase and VS Code compatible formats.
* [GitHub Copilot Hooks Tool Event Payloads](github-copilot-hooks-tool-payloads.md) - Input payload shapes for the preToolUse, postToolUse, and postToolUseFailure hook events in camelCase and VS Code compatible formats, including Claude-format tool name handling for PascalCase PreToolUse.
* [GitHub Copilot Hooks Agent Lifecycle Event Payloads](github-copilot-hooks-agent-lifecycle-payloads.md) - Input and output payload shapes for the agentStop, subagentStart, and subagentStop hook events, including additionalContext accumulation and agent-name matching.
* [GitHub Copilot Hooks Error and Compaction Event Payloads](github-copilot-hooks-error-and-compaction-payloads.md) - Input payload shapes for the errorOccurred and preCompact hook events in camelCase and VS Code compatible formats.
* [GitHub Copilot Notification Hook](github-copilot-hooks-notification-hook.md) - Reference for the CLI-only notification hook event, including its input payload, notification types, additionalContext injection, and matcher on notification_type.
* [GitHub Copilot Hooks Tool Decision Control](github-copilot-hooks-tool-decision-control.md) - Output fields that let preToolUse, postToolUse, and permissionRequest hooks allow, deny, modify, or augment tool calls, including the sandbox-bypass exception for permissionRequest.
* [GitHub Copilot Hooks Agent Stop Decision Control](github-copilot-hooks-agent-stop-decision-control.md) - Output fields for agentStop and subagentStop hooks that block and force another turn or rewrite a subagent response, including merge rules and the eight-block runaway guard.
* [GitHub Copilot Hooks Matchers and Tool Names](github-copilot-hooks-matchers-and-tool-names.md) - How the matcher regex field filters hook invocations per event, the Claude-format matcher semantics for PascalCase events, and the runtime and Claude tool names used for matching.
* [GitHub Copilot Hooks Exit Codes and Failure Behavior](github-copilot-hooks-exit-codes-and-failure-behavior.md) - How Copilot interprets command hook exit codes and timeouts, including the fail-closed preToolUse exception, exit code 2 semantics per event, and fail-open timeouts.
